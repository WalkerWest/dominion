Software platform

Managed Kubernetes.
No ops required on your end.

Every client workload runs in a dedicated Kubernetes namespace with resource quotas, network isolation, and RBAC. Clients deploy containers. Dominion manages everything below that line.

  • Multi-tenant namespace isolation
    Dedicated Kubernetes namespace per client. GPU quotas, network policies, and RBAC scoped to the client's namespace. No cross-tenant data access at the platform level.
  • Volcano batch scheduler
    Gang scheduling for distributed training runs. Job queuing and priority management. Training workloads don't compete with inference workloads at the scheduler level.
  • Private container registry
    Client-specific private registry. Model containers never leave the Dominion network boundary. TLS 1.3 in transit, AES-256 at rest.
  • Prometheus + Grafana monitoring
    GPU utilization, memory pressure, job completion, and throughput metrics visible to clients via a read-only Grafana dashboard. Alerting included at all tiers.
  • HIPAA-compliant namespace
    Enhanced audit logging, dedicated network segment, and BAA available for healthcare clients. Available at Inference Cloud Growth tier and above.
  • MLOps Suite (T3 add-on)
    Customers with internal data science teams can add the full MLOps Suite on top of the platform layer: MLflow for experiment tracking and model registry, Prefect for pipeline orchestration, Feast for the feature store, BentoML for model serving, and Evidently for drift monitoring. T1 and T2 customers get the platform layer alone; T3 customers get the platform layer plus this development environment.
